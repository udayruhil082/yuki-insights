Where the information comes from

Each brand is searched three ways: general news, Indian marketing press (afaqs!, exchange4media, ET BrandEquity, Campaign India, BestMediaInfo and others) and the brand's own websites. YouTube channels and brand online stores are checked too. Every item links to its original source with its date, and is labelled Official, Trade press, News, Logged by team or Fiama team.

Labels such as Launch or Campaign are picked from keywords, so open the source before quoting a claim in a report. Instagram is never scraped. Use Log a post for reels and creators you spot.

Connect to your GitHub

Connect once so this app downloads the daily updates from your GitHub project, and so Refresh and Log a post work from here. Fiama activity stays on this laptop.

  1. Open GitHub key settings and name the key “Yuki Insights”.
  2. Repository access: Only select repositories, then pick your project.
  3. Permissions: Actions, Contents and Issues, each set to Read and write. Click Generate and copy the key.
